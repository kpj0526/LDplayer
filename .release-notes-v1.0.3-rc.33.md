# ldmanager v1.0.3-rc.33

- Per-LD Test capture validates the game screen before Start is available.
- Windows Graphics Capture is enabled only when its frame passes the same validation as the ADB frame; ADB remains the automatic fallback.
- A failed newer Test capture disables Start again for that LD.
- Account input taps reuse one serial-scoped ADB shell to reduce process churn.

## Customer-PC validation

Launch LDPlayer, map each ADB serial, and press **Test capture** on each LD before Start. Verify a full game cycle and long-running multi-account stability on the target PC.
