# Test Plan

## 자동 테스트

- OpenCV 템플릿 매칭: 각 UI 요소의 match/no-match/low-confidence 및 ROI 밖 오인식을 검증한다.
- OCR: `모든 몬스터 처치`, `200`, `200/200`의 정상·유사문구·부분수량을 검증한다. 문구 단독 또는 수량 단독은 목표 판정 실패여야 한다.
- 상태 머신: 슬롯 1→5 순서, 비목표의 제한 재갱신, 목표 슬롯 유지, 팝업 미확인 시 확인 탭 금지, 0~199/200에서 완료/보상 탭 금지를 검증한다.
- 전환 검증: 완료→보상→수령→결과→닫기→목록 복귀와 각 탭 뒤 예상 화면 변화가 없을 때 중단하는지 검증한다.
- 내결함성: 가변 비용, 낮은 신뢰도, 예상 밖 화면, 정체, 반복 실패, ADB 오류/해제, 계정 하나의 오류가 다른 Worker에 미치는 영향이 없는지를 검증한다.
- 격리: LD1~LD9 병렬 Worker가 캡처와 `input tap` 모두 자기 serial에만 전달하는지 검증한다.

## 실제 환경 검증

사용자가 제공한 동일 해상도 LD1~LD9와 원본 화면 자료로 시작한다. 한 계정을 감독 모드에서 검증한 뒤 다계정으로 확장한다. 실제 검증에는 팝업의 모든 비용 변화, 비목표→목표 재갱신, 0~199/200, 200/200/완료 표시, 보상 수령과 결과 닫기, 재갱신 후 반복을 포함한다.

실제 화면에서 최소 한 번의 전체 순환과 완료·보상·재갱신 반복, LD1~LD9 동시 실행 시 계정 간 입력 미혼합이 확인돼야 한다. 원본 화면, 템플릿, 실제 ADB 매핑이 없으면 해당 항목은 `BLOCKED_REAL_ENVIRONMENT`다.
