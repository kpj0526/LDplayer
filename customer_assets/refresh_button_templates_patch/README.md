# 갱신 버튼 템플릿 보완 패치

기존 목표 임무 전용 ZIP에 누락된 실제 갱신 버튼 템플릿입니다.

- `button_refresh_4400.png`
- `button_refresh_6600.png`
- `button_refresh_9900.png`
- `button_refresh_14900.png`
- `refresh_currency_icon.png`

네 가지 금액은 고객 영상에서 직접 확인된 갱신 단계입니다. 실행 시 고정좌표로 클릭하지 말고 현재 ADB 캡처에서 네 템플릿 중 하나를 찾아, 발견된 사각형 중심을 동일한 ADB 시리얼에 터치합니다.

`9,900` 템플릿은 팝업 뒤에서 어두워진 장면에서 추출됐으므로 밝기 변화에 강한 회색조/에지 매칭 또는 아이콘 보조 판정을 적용해야 합니다.
