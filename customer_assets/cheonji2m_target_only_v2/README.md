# 십이지천2M 목표 임무 전용 구현 패키지

고객 화면녹화에서 추출한 이미지와 Manager 구현 프롬프트를 한 ZIP으로 구성했습니다.

## 유일한 목표 조건

`모든 몬스터 처치` 문구와 `/200`이 같은 임무 화면에서 모두 확인되는 경우에만 수락합니다.

- 목표 조건 충족: 수락 후 다음 슬롯으로 이동
- 목표 조건 불충족: 수락하지 않고 다시 갱신
- 인식 실패: 즉시 갱신하지 않고 재캡처 후 오류 처리

비목표 임무별 이미지나 이름은 등록하지 않습니다. `/250`, `/300`, 특정 몬스터 이름 등은 모두 목표 조건 불충족으로 처리합니다.

## 구성

- `assets/templates/`: 영상에서 추출한 실행용 초기 템플릿
- `reference_frames/`: 목표 임무·갱신·진행·완료·보상 상태 원본 프레임
- `template_manifest.json`: 템플릿 용도와 클릭 규칙
- `docs/MANAGER_PROMPT.md`: Manager에게 전달할 전체 구현 지시

영상의 마우스 커서가 일부 버튼 이미지에 포함돼 있으므로 초기 개발에는 그대로 사용하되, 고객 PC의 ADB 원본 캡처를 확보하면 커서 없는 이미지로 교체할 수 있게 구현해야 합니다.
